# Neon Racer V53 — 寫實追尾賽車介面

## 介面方向
依照使用者提供的開放世界賽車畫面重新設計，但沒有直接複製品牌圖示或遊戲素材。

## 已完成
- 更低、更貼近車尾的第三人稱鏡頭
- 路面中央導航線
- 直線為藍色、中彎為黃色、急彎為紅色
- 左下路線小地圖與前方轉彎距離
- 上方技巧分數與倍率
- 漂移、反打、擦身與氮氣可累積技巧
- 撞車、護欄或施工障礙會中斷連段
- 右下真車風格速度表、檔位與氮氣量
- 手機新增 DRIFT 與 N₂O 按鍵
- 鍵盤 Space 漂移、Shift／N 氮氣
- 設定可分別關閉導航線、技巧 HUD 與小地圖
- 保留 V52 的單檔啟動、安全模式與修復工具

## 注意
- 這是 Canvas 偽 3D，不是真正的 3D 模型引擎。
- 介面是參考風格重做，不是原遊戲 UI 的逐像素複製。
