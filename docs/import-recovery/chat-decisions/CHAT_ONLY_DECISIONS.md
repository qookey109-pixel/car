# CHAT_ONLY_DECISIONS

以下決策目前只在 Project 對話摘要、附件附帶文字或參考圖中確認，尚未確認已寫入正式 Repository。

1. 2026-07-17 要大幅修改遊戲 UI，參考「賽車遊戲 UI 介面展示.png」的樣式。
2. 視角仍以當時遊戲內既有追尾鏡頭為主，不因參考圖改成其他鏡頭。
3. 手機橫向優先。
4. 左下方向控制；右下 GAS、BRAKE、NITRO、DRIFT。
5. 車輛選擇以六種顏色為主，不採新手型／高速型分類。
6. 目標最高速度曾指定約 320。
7. AI 至少需要兩名較強對手。
8. 撞牆必須明顯減速。
9. 轉向要更緊、抓地力更強、加速更快。
10. 漂移包含分數、胎痕、煙霧與氮氣系統。
11. Rapier 真物理版本曾發生啟動問題，因此曾回退到可玩的穩定版。
12. UI 改版不得重做或覆蓋 V41、V48～V53 已驗證成果。
13. V53 是目前最新可恢復候選，不等於已確認 GitHub main。
14. 2026-07-17 的參考圖晚於 V53，但沒有證據證明已有 V54 程式。
