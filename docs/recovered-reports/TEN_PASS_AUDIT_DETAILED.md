# Neon Racer V41 — 十輪精修稽核報告

## 第 1 輪：操控回應
發現：左右同按與油門、煞車同按時缺少統一規則，高速轉向可能過敏。
修正：新增舒適／運動／精準模式、轉向與油門漸進曲線、煞車優先及衝突消除。
驗證：方向衝突、煞車優先與高速轉向縮放測試通過。

## 第 2 輪：鏡頭穩定
發現：視角切換、彎道傾斜與高速震動可能造成突跳或暈眩。
修正：新增鏡頭阻尼、視線跟隨、速度起伏、地平線穩定及三種鏡頭動態模式。
驗證：深度、橫滾與減少動態效果測試通過。

## 第 3 輪：AI 預測
發現：AI 只看當前距離，兩台車可能同時搶同一車道。
修正：加入 TTC 碰撞時間預測、車道區段預約及預測煞車。
驗證：TTC、非追近車輛與車道互斥測試通過。

## 第 4 輪：長時間記憶體
發現：煙霧、碎片與胎痕持續建立及刪除物件，長時間可能增加 GC 卡頓。
修正：改為固定容量物件池與回收重用。
驗證：容量限制、死亡回收及重用統計測試通過。

## 第 5 輪：音訊混音
發現：引擎、碰撞、雷聲及摩擦聲重疊時可能產生爆音，Safari 亦可能暫停音訊。
修正：加入主音量、動態壓縮器、靜音匯流排及使用者手勢喚醒。
驗證：Web Audio 節點及控制介面契約檢查通過。

## 第 6 輪：設定安全
發現：舊版、損壞或手動改寫的 localStorage 可能含異常數值。
修正：加入 enum、數值範圍、布林值驗證與自動遷移。
驗證：超界、錯誤型別及非法選項測試通過。

## 第 7 輪：安全區與版面
發現：小尺寸橫向畫面、瀏海及放大按鈕可能導致 HUD 或控制重疊。
修正：加入 HUD 縮放、控制高度、動態安全縮放及極小橫向版面。
驗證：844×390、812×360 與大型螢幕配置測試通過。

## 第 8 輪：真機診斷
發現：真機問題缺乏統一的環境及錯誤資料。
修正：新增可下載診斷報告，包含版本、FPS、設定、裝置、畫質及最後錯誤。
驗證：診斷資料格式與環境欄位測試通過。

## 第 9 輪：繪製預算與 LOD
發現：遠方道路細節仍可能消耗不必要的 Canvas 繪製成本。
修正：加入逐幀細節預算、投影尺寸 LOD、遠景建築數量調節。
驗證：近景、遠景、低畫質及背景數量測試通過。

## 第 10 輪：執行期自我修復
發現：背景恢復、極端數值或非有限浮點數可能造成物理狀態失控。
修正：偵測長幀、清除殘留輸入，並自動修復玩家與 AI 的 NaN、Infinity 及越界狀態。
驗證：長幀偵測、玩家修復與車隊修復測試通過。

## 最終驗證
- 所有 JavaScript 檔案通過 `node --check`
- HTML 必要 ID 與模組載入完整性檢查
- Service Worker 快取清單完整性檢查
- 九組模組回歸測試
- Node 模擬 DOM 啟動、素材載入、設定開啟、倒數及加速 smoke test
